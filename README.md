# No Restock Reload Mod

Version 1.0 of the No Restock Reload Mod for Gunner HEAT PC. This mod lets you reload from storage racks without having to restock the ready rack first. 

***Installation***  
This mod requires MelonLoader Version 0.6.1.

To install, extract the "NoRestockReload.dll" file from releases and unzip the "NoRestockReload" assets folder into the /mods/ folder.
